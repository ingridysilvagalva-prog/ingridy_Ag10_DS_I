# 📊 Projeto de Cálculo de Notas

Este projeto foi desenvolvido com o objetivo de automatizar o cálculo de notas de alunos, facilitando a identificação de aprovação ou reprovação e gerando um relatório simples.

## 💡 Funcionalidades

* Cálculo da média de duas notas
* Verificação de aprovação ou reprovação
* Geração de relatório com nome, média e situação

## ⚙️ Como funciona

O programa recebe o nome do aluno e duas notas, calcula a média e informa se o aluno foi aprovado ou reprovado.

## 🧠 Estrutura do código

O código foi dividido em funções para facilitar a organização:

* `calcular_media` → calcula a média das notas
* `verificar_aprovacao` → verifica se o aluno foi aprovado
* `gerar_relatorio` → exibe as informações do aluno

## 💻 Tecnologias utilizadas

* Python

Média: 6.0
Situação: Aprovado
